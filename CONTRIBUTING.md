# Contributing

This repository contains the Hacker House Goa 2026 Task #1 builder identity generator.

## Development workflow

1. Create a focused branch from `main`.
2. Keep UI, generation, and documentation changes scoped and reviewable.
3. Run the project locally and verify the builder flow before opening a pull request.
4. Do not commit secrets, local environment files, build output, or editor metadata.

## Pull requests

Describe the user-facing change, implementation details, and testing performed. Include screenshots when a visual change affects the builder experience.

## Commit messages

Prefer concise messages such as:

```text
feat: improve builder card layout
fix: handle missing upload data
docs: update deployment notes
```
