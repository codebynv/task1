# Task 1 Demo Checklist

A short pre-demo checklist for the Hacker House Goa Task #1 Builder ID experience.

## Builder ID

- [ ] Upload a valid portrait image.
- [ ] Enter the builder name.
- [ ] Select or enter the builder role.
- [ ] Select the relevant technology stack.
- [ ] Generate the Builder ID.
- [ ] Confirm the output is a real PNG image.

## Team Frame

- [ ] Add two builders.
- [ ] Add a third builder when needed.
- [ ] Verify each builder has the intended name and photo.
- [ ] Generate the combined Team Frame.
- [ ] Confirm the final image is readable on mobile.

## Sharing

- [ ] Download the generated image successfully.
- [ ] Verify the X share action opens the expected share flow.
- [ ] Confirm the required #FrameInGoa hashtag is included.

## Edge cases

- [ ] Missing image is handled cleanly.
- [ ] Missing required text is handled cleanly.
- [ ] Very long names do not break the layout.
- [ ] The experience remains usable on a narrow mobile viewport.

## Final check

- [ ] No local environment files or secrets are committed.
- [ ] Test the live deployment before sharing the demo URL.
