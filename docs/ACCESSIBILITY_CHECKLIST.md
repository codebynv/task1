# Accessibility Checklist

Before a public demo, verify:

- [ ] Every important input has a visible label.
- [ ] Buttons have clear action text.
- [ ] Keyboard focus is visible.
- [ ] Text remains readable at mobile widths.
- [ ] Generated images have meaningful surrounding context.
- [ ] Error messages are understandable without relying only on color.
- [ ] Interactive controls have sufficient target size.

The builder flow should remain understandable even when the user does not already know the interface.
