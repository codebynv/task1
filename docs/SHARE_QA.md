# Share QA

Before release, test the sharing path end to end.

- [ ] The generated image is complete.
- [ ] The download has the expected format.
- [ ] The share action opens the intended destination.
- [ ] Required hashtags are preserved.
- [ ] Long names do not break the image.
- [ ] Sharing does not expose unexpected local file paths or private data.

Test the actual downloaded artifact as well as the in-page preview.
