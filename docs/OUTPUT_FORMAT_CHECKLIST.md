# Output Format Checklist

Before changing generated image output, verify:

- The exported file uses the expected format.
- Dimensions and aspect ratio match the selected option.
- Text is legible at the final output size.
- Transparency behavior is defined where relevant.
- Unsupported formats fail with a clear message.
- Downloaded bytes match the generated preview.
- Filenames are safe and predictable.

Test the actual downloaded file across supported browsers.
