# Responsive Checklist

Before publishing the Builder ID experience:

- [ ] Test narrow mobile width.
- [ ] Test tablet width.
- [ ] Test desktop width.
- [ ] Verify upload controls remain usable.
- [ ] Verify generated previews do not overflow.
- [ ] Verify long names remain readable.
- [ ] Verify download and share controls remain accessible.

The core generation flow should remain usable without horizontal scrolling.
