# Image Export QA

Verify generated files rather than relying only on the preview.

- Export with default settings.
- Test long labels and optional fields.
- Test supported portrait and landscape images.
- Confirm output dimensions and file type.
- Check text clipping and overlapping elements.
- Confirm invalid input produces a useful error.
- Open the downloaded file in an image viewer.

Record browser and test inputs when reporting a defect.
