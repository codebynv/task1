# Image Export Boundary Checks

Review export behavior at supported limits:

- minimum and maximum output dimensions,
- very long text and unusual characters,
- missing optional fields,
- portrait and landscape source images,
- unsupported or corrupted image files,
- safe output filenames,
- interrupted or failed downloads.

Check the actual exported file for dimensions, format, clipping, and readability. Document observed behavior rather than assuming every case is supported.
