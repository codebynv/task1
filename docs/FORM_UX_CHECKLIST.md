# Form UX Checklist

- [ ] Required fields are obvious.
- [ ] Validation appears near the relevant field.
- [ ] Errors explain how to recover.
- [ ] Entered values remain available after validation errors.
- [ ] Keyboard navigation reaches all controls.
- [ ] Loading state prevents accidental duplicate generation.
- [ ] Small screens do not hide important actions.

Test the complete form rather than checking controls individually only.
