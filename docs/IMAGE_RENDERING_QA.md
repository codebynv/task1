# Image Rendering QA

- [ ] Preview matches the downloaded output.
- [ ] Long names do not overlap other elements.
- [ ] Uploaded images preserve the intended crop.
- [ ] Text remains legible at the target output size.
- [ ] Unsupported images fail with a clear message.
- [ ] Team Frame layouts work for supported participant counts.
- [ ] Repeated generation does not reuse stale preview data.

Inspect the final file, not only the browser preview.
