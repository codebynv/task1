# QA Checklist

Before sharing the Builder ID app:

- [ ] Generate an ID with valid input.
- [ ] Try missing and invalid inputs.
- [ ] Test a long builder name.
- [ ] Generate a Team Frame with supported participant counts.
- [ ] Download and inspect the generated image.
- [ ] Test share behavior.
- [ ] Check mobile layout and keyboard usability.

Record reproducible failures with steps and expected versus actual behavior.
