# 01 · THE OPEN TRIAL

> **HACKER HOUSE GOA 2026 · TASK #1**  
> The brief: upload a photo and instantly get back a branded HH Goa 2026 graphic that can be downloaded and shared on X.

The official task offers two formats:

**FORMAT A — PFP FRAME / OVERLAY**  
Wrap the uploaded photo in HH Goa branding for an X profile picture.

**FORMAT B — BUILDER ID CARD**  
Turn the photo, name, stack/role and generated builder title into an event-style identity card.

This build takes **Format B** and pushes it one step further with a **2–3 builder Team Frame**.

# 05 · TEAM FRAME

## **BUILDERS LOOK BETTER TOGETHER.**

The individual Builder ID is extended into a combined **2–3 builder Team Frame**.

Each builder contributes:

```text
NAME
  +
PHOTO
```

The renderer then composes them into one HH Goa themed graphic.

```text
        BUILDER 01
       ┌───────────┐
       │   PHOTO   │
       │   NAME    │
       └─────┬─────┘
             │
             │
┌────────────┴────────────┐
│                         │
▼                         ▼
BUILDER 02             BUILDER 03
┌───────────┐          ┌───────────┐
│   PHOTO   │          │   PHOTO   │
│   NAME    │          │   NAME    │
└───────────┘          └───────────┘
             │
             ▼
       ┌─────────────┐
       │  TEAM FRAME │
       └─────────────┘
```

This keeps the same visual system across solo builders and small teams.

# 09 · PHOTO HANDLING

Real people do not upload perfectly cropped studio portraits.

The task calls out:

- Portrait photos
- Landscape photos
- Off-center subjects
- Different aspect ratios
- JPG
- PNG
- HEIC from iPhone

The uploader therefore handles the photo before it reaches the renderer instead of assuming the user will crop it first.

```text
JPG ──┐
PNG ──┼──→ PHOTO HANDLING ──→ CANVAS ──→ FINAL PNG
HEIC ─┘
```
