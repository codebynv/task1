## 01 · THE BRIEF

The task was to build a web tool where someone uploads a photo and gets a branded Hacker House Goa 2026 graphic that is ready to download and share on X.

The brief allows two directions:

- **Format A — PFP Frame / Overlay**
- **Format B — Builder ID Card**

This implementation focuses on **Format B** and extends it with a **2–3 builder Team Frame**.

### REQUIRED JOURNEY

```text
PHOTO
  ↓
PERSONALIZE
  ↓
GENERATE
  ↓
PREVIEW
  ↓
DOWNLOAD / SHARE
```

The brief calls for common photo formats, fast generation, varied photo aspect-ratio handling, real downloadable output, a working X share flow with `#FrameInGoa`, no login/signup gate, and mobile-friendly use. fileciteturn43file0

---

### TEAM FRAME · 2–3 BUILDERS

The same visual system supports a combined team composition.

Each builder contributes:

- Name
- Photo

The renderer creates one shareable HH Goa themed graphic for the group.

---

## 03 · BUILDER PERSONA ENGINE

The identity generator maps role + stack into themed Builder Classes.

| BUILDER AREA | BUILDER CLASS |
|---|---|
| Cybersecurity | **BUG WHISPERER** |
| AI / ML | **MODEL TAMER** |
| DevOps / Cloud | **PIPELINE PILOT** |
| Data | **DATA EXPLORER** |
| Mobile | **MOBILE CRAFTER** |
| Web3 / Blockchain | **CHAIN BUILDER** |
| Full Stack | **STACK FORGER** |
| Backend | **SYSTEM BUILDER** |
| Frontend | **PIXEL ARCHITECT** |

Role matches receive stronger weight than stack-only matches, with priority rules resolving ties.

> **BUILDER LOGIC**  
> The inputs are not just displayed — they determine the builder identity generated by the app.
